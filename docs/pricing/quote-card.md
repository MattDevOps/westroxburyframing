## The formula

**Final Price = Base + Add-ons + Prep**

- **Base** = the size band below (standard moulding + regular glass + single mat + fit & assemble)
- **Add-ons** = upgrades the customer chooses (glass, extra mats, mounting, handling)
- **Prep** = condition work the piece needs before it can be framed right

**Floor rule:** never quote a line below your wholesale cost x 3 (moulding) or x 2.5 (mat/glass).
Below market is good. Below your floor is a loss. The floor always wins.

## The counter conversation

When a piece needs prep, name the base, name the problem, name the fix, give the choice:

> "For a piece this size I'm usually around **$[base]**, and that already beats Big Picture
> and the shops downtown. But here's the thing -- this canvas is **loose on the bars**. If I
> just frame it as-is it'll ripple behind the glass within a season. So I tighten and reset it
> first -- that's **$[prep]** -- and it's **$[total]** done right. I *can* do the quick version
> for the base price, but it won't come out as nice, and I don't put my name on work like that.
> Done properly it'll be perfect. That's how I'd want it if it were mine."
