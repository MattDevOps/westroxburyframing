# Boston Designers Starter List

> 30 well-known Boston-area independent residential design firms, curated as a starting point for B2B outreach. **No emails — you'll need to add those manually before sending.**

## How this list was made

Compiled from training-data knowledge of the Boston-metro design scene as of January 2026. Sources I used: Boston Magazine "Best of Boston" historical lists, AD100 / ELLE Decor Top Designers pages, Boston Design Center directory, and general industry reputation.

**Important caveats:**

- Firms may have closed, rebranded, or moved since the cutoff — verify each before sending.
- Website URLs are best-effort. About 60% of the rows include a website I'm reasonably confident in; the other 40% have the website blank with "verify website" in the notes.
- Principal names are filled where I confidently know who runs the firm. Several rows have the name fields blank because I didn't want to guess wrong (the AI drafter handles `firstName: null` cleanly — it just opens with "Hi," instead of "Hi [name],").
- This is **not** an exhaustive list. There are dozens more Boston-area designers, especially newer firms post-2024.

## Why no emails

Designers don't publish business emails on their websites — they use contact forms. To turn this list into something you can email, pick a path:

### Path A — Hunter.io / Apollo / Clay enrichment ($30–100, fast)

1. Go to [hunter.io](https://hunter.io), create an account, and use **Domain Search**
2. Paste each firm's domain (e.g. `frankroop.com`)
3. Hunter shows known emails for that domain — typically `firstname@`, `firstname.lastname@`, or a generic `info@` / `hello@`
4. Verify each email's deliverability with their built-in checker (avoids bounces)
5. Add the email back to this CSV before importing

Hunter's free tier covers ~25 lookups/month; their $34/mo plan does 500. Apollo and Clay are similar.

### Path B — Manually research the top 5–10 firms (free, slower)

Pick the firms most likely to convert (hint: `Frank Roop Design Interiors`, `Manuel de Santaren`, `Eleven Interiors`, `Liz Caan & Co.`, `Annsley Interiors` — all have published heavy gallery-wall portfolios). For each:

1. Visit the website's Contact / About page
2. Some firms list `name@firmname.com` patterns directly; some only have a contact form
3. If only a form, send via the form with a subject line like *"Considering you for our preferred-vendor list — frame shop in West Roxbury"* and skip the lead-import flow for that firm

### Path C — Send via contact forms (free, slowest)

Same as Path B but for ALL 30 firms. Each form takes ~3 minutes if you reuse a copy-pasted template. Total time: 1.5 hours.

## How to import this list once you've added emails

1. Open `https://westroxburyframing.com/staff/marketing/leads/import`
2. Paste the entire CSV (including the header row) into the text box, or use the file upload
3. **Default vertical:** Interior designers
4. **Default source:** "Curated Boston designers list 2026-01"
5. Click **Preview** first to see what would be created
6. If preview looks right, click **Confirm and import** to commit

The import dedupes by email, so if you forget to add an email to some rows it'll still import them — they'll just need email added manually later via the lead detail page.
